# 004 - FastAPI als Backend-Framework

## Entscheidung
Für das Backend von CampusHub soll voraussichtlich FastAPI verwendet werden.

## Begründung
- Python kann für Backend und Collector gemeinsam verwendet werden
- gute Unterstützung für REST-Schnittstellen
- automatische Validierung von Request-Daten
- automatische API-Dokumentation
- vergleichsweise schlanker Aufbau

## Hinweis
FastAPI wird zunächst in einem kleinen Prototyp getestet.
Sollte sich das Framework als ungeeignet herausstellen, kann die Entscheidung
während der frühen Entwicklungsphase angepasst werden.
