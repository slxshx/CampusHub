# 001 - Python als Hauptsprache

## Wieso Python?

Python ist im Gegensatz zu C# & PHP was die Alternativen von der Herangehensweise in diesem Projekt wären meine schwächste Sprache. 
Da Python aber dank der unzähligen externen Module zu so gut wie allem fähig ist, habe ich mich dazu entschieden diese Sprache für mein Vorhaben zu verwenden.

### Vorteile

Python ist extrem flexibel - das hilft mir besonders in den verschiedenen Anwendungsfällen die ich in diesem Projekt brauche. 
Bspw. möchte ich in diesem Projekt folgende Module einsetzen: 

- FastAPI (https://fastapi.tiangolo.com/)
FastAPI möchte ich zum bauen einer REST-API nutzen, welche als Schnittstelle zwischen den Geräten im Campus-Netzwerk und der Datenbank dient.

- SQLAlchemy (https://www.sqlalchemy.org/)
Möchte ich nutzen um per Python, SQL-Query's auf die DB zu feuern.

## Nachteile

Wie bereits erwähnt ist Python die Sprache, mit der ich am wenigsten Erfahrung habe. 
Da ich immer sehr viel Wert darauf lege, dass der Code ausschließlich von mir kommt, werde ich mehr Zeit brauchen um alles zum Laufen zu kriegen.
