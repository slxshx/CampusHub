# CampusHub – Quality Session 2026-09-01

## Goal

Verbesserung der Codequalität und Entwicklungsinfrastruktur vor Beginn der
Monitoring- und Collector-Implementierung.

## Planned Tasks

### 1. Repository Typing

- BaseRepository mit Type Hints verbessern
- Generics untersuchen
- Unknown-Typen im LSP reduzieren
- Rückgabewerte der CRUD-Methoden klar definieren

### 2. Automated Tests

- pytest einführen
- manuellen Repository-Smoke-Test als Grundlage verwenden
- Assertions statt manueller Konsolenauswertung
- grundlegenden CRUD-Ablauf automatisiert testen

### 3. CI Pipeline

Eine einfache GitHub-Actions-Pipeline einführen.

Ziel:

Push / Pull Request
    -> Dependencies installieren
    -> Tests ausführen
    -> Build bei Fehlern stoppen

Spätere Erweiterungen:

- Linting
- Type Checking
- weitere Tests
- Security Checks

### 4. Documentation

- wichtige nicht offensichtliche Funktionen mit Docstrings versehen
- Architektur-/Qualitätsentscheidungen dokumentieren
- Ergebnisse der Session festhalten

## Definition of Success

Minimum:

- BaseRepository besser typisiert
- mindestens ein automatisierter pytest-Test

Target:

- CRUD Repository Tests laufen automatisiert
- CI führt Tests bei Push / Pull Request aus

Stretch:

- Linting / Type Checking in CI
